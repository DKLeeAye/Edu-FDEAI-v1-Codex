# EduFDE Frontend

Next.js App Router frontend scaffold for the EduFDE MVP.

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run typecheck
```

## Scope

This scaffold contains only the MVP placeholder shell. Student, teacher, admin, stage workflow, Artifact, and AI Gateway user interfaces will be implemented in later slices.
