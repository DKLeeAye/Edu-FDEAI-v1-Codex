- `docs/dev/current-context.md`
- `docs/dev/progress.md`
- `docs/dev/decisions.md`
- `docs/dev/phase-2-governance.md`

## 三、使用规则

默认开发会话不读取本目录。

需要以下场景时再读取：

- 追溯第一阶段某个决策来源。
- 查验第一阶段验证记录。
- 恢复旧开发治理文档内容。
- 查看阶段性复盘或 student2 走查截图。

不要把本目录内容重新复制回当前 `progress.md` 或 `current-context.md`。
