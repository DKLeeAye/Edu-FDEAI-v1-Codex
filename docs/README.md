## 七、v2.0 统一原则

1. 产品定位统一为：面向高校的 AI 智能体项目交付实训平台。
2. 五阶段统一为：
   - 需求访谈与问题发现
   - 方案定义与可行性判断
   - 知识工程决策
   - 智能体实现与测试
   - 交付验收与运维说明
3. 所有阶段产物沉淀为 Artifact。
4. 所有评分绑定 Rubric 和证据。
5. 所有 AI 调用经过 AI Gateway。
6. 课程绑定实验包版本。
7. 教师拥有最终教学判断权。
8. MVP 裁剪功能，但不裁剪终局地基。
