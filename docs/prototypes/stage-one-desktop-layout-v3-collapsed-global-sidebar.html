训练客户
我们最近确实想提高质检效率，但大家说法不太一样，有人说是漏检，有人说是记录太散。
除了漏检本身，哪个问题最影响您准备客户审厂？
审厂时最麻烦的是异常原因和复检结果追不清，现场解释起来很被动。
继续围绕“影响、后果、频率、责任人”追问客户...

本关目标与提问辅助

训练目标

从客户的表层抱怨中识别真正影响业务结果的核心痛点。

提问技巧
  • 追问影响，而不是只问现象。
  • 让客户举最近一次具体例子。
  • 区分效率问题、质量问题和管理问题。

刘海峰 · 制造工厂厂长

面临客户审厂压力，希望用 AI 改善质检资料检索和异常追溯。实战模式下客户不会主动透露隐藏约束，需要学生主动挖掘。

正式客户
我们想看看 AI 能不能帮质检团队少花点时间找资料，尤其是审厂前那几天。
现在审厂前最耗时的是哪类资料整理？这些资料分散在哪些地方？
质检记录、异常处理和复检结果分散在几个表里，关键是很多说明靠老师傅记忆。
这些资料不完整时，会影响审厂通过，还是主要影响内部效率？
