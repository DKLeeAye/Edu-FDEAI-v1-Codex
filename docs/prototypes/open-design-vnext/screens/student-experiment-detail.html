Business Context

先看清工厂正在经历什么

核心业务矛盾

工厂一直在做质检，但记录分散在 MES、Excel、纸质质检单、SOP、不合格品处理单和客户整改材料中。审厂前，质量负责人需要跨系统拼接证据，才能说明某批次异常如何发现、处理、复检和整改。

资料分散

追溯说明需要同时引用流程文件、质检记录、客户要求和整改证明。

字段不完整

MES 只保留部分结构化字段，异常原因、处置过程、复检结果经常缺失。

一线阻力

如果方案要求质检员重复录入完整数据，项目落地会变成额外负担。

Agent Scope

这个智能体解决什么，也不解决什么

页面保留真实边界，是为了训练学生不要把“AI 能生成回答”误认为“项目可以交付”。

应该解决

  • 查询质检 SOP、不合格品处理流程和审厂要求
  • 基于已有记录生成异常追溯说明初稿
  • 识别追溯字段与证据缺口
  • 辅助准备审厂材料清单和客户问答

不能承诺

  • 不替代 MES、ERP 或质量管理系统
  • 不自动判定产品是否合格
  • 不伪造缺失的质检数据
  • 不替代质量负责人作最终判断

Agent Tasks

智能体必须经得起这些任务测试

这些问题会在阶段四和阶段五作为测试与验收依据。

制度查询 不合格品发现后应如何处理？

检索 SOP 与处理流程，给出步骤化回答，并提醒保留记录。

审厂准备 质检记录数字化需要准备哪些信息？

区分必须字段和建议字段，帮助质量负责人准备材料。

追溯说明 根据异常记录生成审厂用追溯说明。

引用已有记录，标注缺失信息，不把不确定内容写成事实。

字段检查 这条记录能否支撑完整追溯？

检查批次、检验员、处置结果、复检结果、整改措施等字段。

范围外拒答 今天股市行情怎么样？

明确拒答，并引导回质检流程、异常追溯或审厂材料问题。
