Agent Architecture

一个可交付智能体由哪些模块组成？

制造业质检追溯智能体的核心不是“会回答”，而是能在证据、边界和流程约束下稳定回答。

01

用户问题入口

接收质检员、质量负责人或审厂准备人员提出的批次、工序、缺陷与材料问题。

02

边界判断

先判断是否属于质检追溯范围，是否涉及责任认定、处罚建议或资料不足。

03

RAG 检索

调用阶段三设计的知识库、召回策略、元数据过滤和风险边界规则。

04

回答与引用

按证据组织答案，标注来源、批次号、标准条款和记录版本。

05

转人工与日志

遇到记录冲突、责任结论或证据缺口时转人工，并保存问题、证据和处理状态。

Prompt & Workflow

Prompt 不是一句角色设定，而是一组产品行为规则。

学生需要把智能体角色、任务范围、引用要求、拒答边界和转人工条件写成可测试的规则。

角色与任务

你是制造业质检追溯助手，帮助质量负责人查询批次、工序、缺陷、整改和审厂材料。

证据要求

回答必须引用 MES、Excel 台账、SOP 条款、整改记录或附件编号，不得补造来源。

边界规则

资料缺失时说明缺口；记录冲突时并列证据；责任判定、处罚建议和客户承诺转人工。

输出格式

先给结论，再列证据来源，最后给待确认事项和下一步建议。
