Dify Guided Practice

按真实 Chatflow 流程完成一次 Dify 上手。

学生需要在 Dify 中创建 Chatflow 应用，理解默认画布里的开始、LLM、直接回复节点，完成模型配置、连线检查、预览调试和发布回填，确认完成后才能进入正式智能体构建。

完成标准 8 个 Chatflow 操作步骤 + 1 条发布记录

每一步都要勾选完成；节点配置、连线检查、发布链接和调试记录保存后，平台才允许进入正式构建工作台。

Before You Start

先认清 Chatflow 画布里的关键对象。

下面每个步骤都会围绕真实 Dify 截图里的工作室、Chatflow 类型、节点画布、右侧配置面板、预览和发布展开。

应用类型

选择 Chatflow

在工作室点击创建空白应用，应用类型必须选择 Chatflow，而不是普通聊天助手。

开始节点

接收用户输入

默认开始节点会提供用户输入变量，例如 query 和 files，后续节点要引用这些变量。

LLM 节点

配置模型与上下文

右侧面板需要选择模型、写入指令，并确认上下文变量来自用户输入。

直接回复

输出 LLM 结果

直接回复节点要读取 LLM 的 text 输出，并和前后节点保持正确连线。

预览发布

调试后再发布

先用 Preview 验证流程可运行，再复制发布链接回填到 EduFDE。

01

进入工作室，切到 Chatflow 创建入口。

目标：确认账号可用，并能找到截图中的工作室、Chatflow 类型和创建空白应用入口。

Dify 中这样做

  1. 打开学校提供的 Dify 地址，使用课程账号登录。
  2. 顶部导航进入 工作室。
  3. 在应用类型筛选中找到 Chatflow，再点击 创建空白应用。
  4. 不要从模板导入 DSL，本页只做 Chatflow 新手练习。

完成凭证

02

创建 Chatflow 空白应用。

目标：按照截图中的创建弹窗，明确选择 Chatflow，并填写练习应用名称。

Dify 中这样做

  1. 点击 创建空白应用。
  2. 在应用类型里选择 Chatflow，确认不是“工作流”或“聊天助手”。
  3. 应用名称填写：质检资料问答练习应用。
  4. 应用描述填写：用于练习 Chatflow 节点配置、连线、预览和发布回填。
  5. 点击 创建 进入画布。

回填平台

03

认识 Chatflow 画布和默认节点。

目标：先看懂截图中的三个节点和右侧配置面板，再开始改配置。

画布上需要识别

开始 / 用户输入 LLM 直接回复
  1. 开始节点：接收用户问题和文件输入。
  2. LLM 节点：负责理解用户问题并生成回答。
  3. 直接回复节点：把 LLM 的 text 输出给用户。
  4. 右侧配置面板：点击节点后会显示模型、上下文、记忆、输出等配置。

回填平台

04

检查开始节点的用户输入变量。

目标：理解后续 LLM 节点的上下文变量来自哪里。

Dify 中这样做

  1. 点击画布中的 开始 / 用户输入 节点。
  2. 查看默认输入变量，重点确认 query 是否作为用户问题输入。
  3. 如果课程环境提供文件输入，确认 files 是否存在；本练习不要求上传正式资料。
  4. 不要删除默认输入变量，后面的 LLM 节点要引用它们。

回填平台

05

配置 LLM 节点的模型、上下文和指令。

目标：让 Chatflow 具备最基本的质检问答边界，而不是开放式闲聊。

LLM 节点配置步骤

  1. 点击 LLM 节点，确认右侧出现 LLM 设置面板。
  2. 在 模型 中选择学校指定模型；如果暂未指定，记录你实际选择的模型名称。
  3. 在 上下文 中引用开始节点的用户问题变量，例如 用户输入 / query。
  4. 在指令或系统提示中写入下面的质检问答边界。
  5. 保持“记忆”开启或按教师要求设置记忆窗口；本练习先不启用视觉和结构化输出。

建议写入 LLM 指令

你是制造业质检资料问答助手。
你只能根据课程提供的质检 SOP、质检记录和审厂材料回答。
回答时必须说明资料来源或引用依据。
如果资料不足、记录冲突或涉及责任判定，请提示需要人工确认，不要编造结论。
回答应简洁，优先列出批次号、工序、缺陷类型和需要准备的审厂材料。

回填平台

06

配置直接回复节点，并检查连线。

目标：确认 Chatflow 的输出真的来自 LLM 节点，而不是断在画布中间。

Dify 中这样做

  1. 确认画布连线为：开始节点 → LLM 节点 → 直接回复节点。
  2. 点击 直接回复 节点，在回复内容里选择 LLM / text 输出变量。
  3. 如果连线断开，拖拽节点右侧连接点到下一个节点左侧连接点，直到流程线连接成功。
  4. 点击画布上方 滚动至选中节点 或缩放工具，确认三个节点都在可视范围内。
本练习只要求掌握节点连线和 LLM 输出变量。正式知识库节点、条件分支和工具调用会在后续构建工作台完成。

回填平台

07

使用 Preview 完成一次 Chatflow 调试。

目标：确认画布能从用户输入走到 LLM，再由直接回复节点输出。

建议测试问题

  • B-2026-0412 批次审厂前需要准备哪些质检资料？
  • 如果 MES 记录缺少异常原因，能否直接判断责任部门？
  • 外观划伤问题需要引用哪些 SOP 条款？
  1. 点击画布右上角 Preview / 预览。
  2. 在预览窗口输入上面的任一问题。
  3. 观察是否出现 Workflow Process 或节点运行过程。
  4. 如果无回复，回到画布检查 LLM 模型、上下文变量和直接回复节点变量。

回填平台

08

发布 Chatflow 应用，并把访问链接粘贴回平台。

目标：理解正式项目为什么必须提交可访问的 Dify 发布链接，平台后续会用它进行自动化测试。

Dify 中这样做

  1. 点击画布右上角 发布 / Publish。
  2. 确认应用可以通过链接访问。
  3. 复制发布链接，不要复制控制台编辑地址。
  4. 保存后回到 EduFDE，粘贴发布链接和调试记录。

回填平台

Why Sync

为什么要回填平台

Dify 是操作环境，EduFDE 是教学评审环境。学生需要把关键配置、测试记录和发布链接同步回来，教师和平台自动测试才能看到过程证据。
