07 / Retrieval Strategy

召回策略：让问题命中正确证据，而不是相似但无关的材料。

本页通过制造业质检样本演示向量召回、关键词召回、混合召回和元数据过滤的差异。学生需要判断不同业务问题应该采用哪种召回组合。

Concept

召回不是“找最像的一段话”，而是先缩小业务范围，再取可信证据。

在质检追溯场景中，批次号、工序、缺陷类型和标准版本通常比语义相似度更能决定答案是否可用。

01

向量召回

适合“审厂要准备哪些追溯材料”这类语义问题，但可能命中相似主题的错误批次。

02

关键词召回

适合批次号、缺陷代码、SOP 编号等精确查找，但不擅长理解同义表达。

03

混合召回

先用元数据过滤业务范围，再合并向量分和关键词分，最适合审计型问答。

Score Anatomy

为什么有的结果语义很像，却不应该排第一？

质检知识库的召回排序不能只看向量相似度。业务过滤、关键词命中和来源可信度会决定证据是否能进入回答生成环节。

Vector

语义相似度

判断问题和知识块主题是否接近，能处理“审厂材料”“追溯证据”等不同说法。

Keyword

精确命中

检查批次号、SOP 编号、缺陷代码、工序名称等是否直接出现。

Metadata

业务过滤

先限定批次、工序、标准版本或资料类型，避免相似但不可引用的内容进入 Top-K。

Source

来源可信

MES、正式 SOP、审厂清单优先级通常高于备忘录和未标注附件。

Decision Practice

为不同质检问题选择召回策略。

判断时要先看问题是否需要精确字段，再决定是否使用语义扩展和元数据过滤。

Case A

审厂前查询某批次的完整质检证据

问题同时包含批次号、证据类型和审计语境，必须避免命中其他批次的相似材料。

Case B

查找 SOP-QC-014 第 4.2 条的当前版本

问题包含明确文件编号和条款号，优先保证精确命中与版本字段正确。

Case C

分析“外观划伤”是否在近期重复发生

学生需要同时找到缺陷台账、终检记录和整改材料，不能只看一条相似文本。
